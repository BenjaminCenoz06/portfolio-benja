# Benjamín Cenoz — Frontend Developer Portfolio

Portfolio interactivo y visual de alto impacto para **Benjamín Cenoz**, Frontend Developer de Córdoba, Argentina.

## 🚀 Características
- **Hero & Identity**: Presentación visual editorial con iluminación dramática de estudio, marquesina gigante infinita y badge de ubicación.
- **Proyectos seleccionados**: Showcase interactivo con cursor flotante de previsualización en tiempo real y galería doble con desplazamiento y capturas reales de los sitios.
- **Capacidades**: Secciones de Frontend Development, Web Design, Interactive Experiences y E-commerce con acordeón interactivo.
- **Metodología**: Carrusel interactivo de proceso (*Diseño, Desarrollo, Interacción, Iteración*).
- **Proyectos destacados**:
  - **Hotel Enfoque Studio**: [hotel-enfoquestudio.netlify.app](https://hotel-enfoquestudio.netlify.app/)
  - **Enfoque Inmobiliaria**: [inmobiliaria-studio.netlify.app](https://inmobiliaria-studio.netlify.app/)
  - **Alba Dental**: [clinica-dental-studio.netlify.app](https://clinica-dental-studio.netlify.app/)
  - **Café Enfoque**: [cafe-enfoque.netlify.app](https://cafe-enfoque.netlify.app/)
  - **FONO Shop**: [fono-shop.netlify.app](https://fono-shop.netlify.app/)
  - **BAKU Shop**: [baku-shop.netlify.app](https://baku-shop.netlify.app/)

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 moderno (Variables CSS, Flexbox, Grid, Animaciones, Clamp)
- JavaScript Vanilla ES6+ (Micro-interacciones, parallax, custom cursor, sliders interactivos)
- Tipografía Geist (Google Fonts)

## 💻 Ejecución local
Puedes abrir directamente el archivo `index.html` en tu navegador o iniciar un servidor local con `node server.js` en el puerto 3000.
