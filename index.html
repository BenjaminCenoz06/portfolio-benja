Lo que hago

Frontend · Web Design · Interaction · Creative Development. Soluciones web donde el diseño y la ingeniería se encuentran para generar valor.

Construyo interfaces modernas, responsive y dinámicas utilizando tecnologías web actuales. Arquitectura de componentes limpia, optimización de carga y código mantenible.

HTML5 semántico CSS3 moderno JavaScript ES6+ React Next.js Responsive

Diseño experiencias visuales con foco en composición, tipografía, jerarquía, interacción y detalle. Estética editorial adaptada a la identidad de cada rubro y marca.

UI/UX Tipografía Composición editorial Jerarquía visual Diseño adaptativo

Incorporo animaciones, transiciones y microinteracciones para que cada sitio tenga una experiencia más atractiva. Movimiento que guía la atención del usuario sin entorpecer el flujo de navegación.

Microinteracciones Transiciones CSS Parallax Scroll effects Motion UI

MI FORMA DE TRABAJAR
"Primero pienso cómo debería sentirse la experiencia. Defino la composición, la tipografía y la dirección de arte para que comunique con fuerza."

01. Diseño

Conceptualización visual & Jerarquía

"Después convierto esa idea en una interfaz funcional y responsive. Código limpio, semántico y preparado para cualquier dispositivo."

02. Desarrollo

Frontend moderno & Arquitectura sólida

"Agrego movimiento, transiciones y detalles que mejoran la experiencia. Microinteracciones que logran que la web se sienta viva."

03. Interacción

Animaciones, dinamismo & Motion UI

"Pruebo, ajusto y sigo mejorando hasta conseguir el resultado buscado. Cada detalle y cada breakpoint cuentan."

04. Iteración

Pulido continuo & Perfección de detalles

Sobre mí

"Me interesa hacer que la web se sienta tan bien como se ve."

Código, diseño y movimiento para crear experiencias digitales.

Soy Benjamín Cenoz, desarrollador frontend de Córdoba, Argentina.

Me enfoco en crear sitios web modernos, visuales e interactivos, combinando desarrollo frontend con diseño y experiencia de usuario.

Me gusta experimentar con interfaces, animaciones, layouts, efectos de scroll y diferentes formas de presentar contenido en la web.

Actualmente también estudio Técnico en Informática y continúo desarrollando proyectos propios y para distintos rubros.
